# Onboarding earns the first action, doesn't gate it

The user can use the app before signing up, before granting permissions, before completing a tour. Onboarding sells; it doesn't toll.

## What it means

The first launch is sacred — the user has just downloaded the app and is at peak intent. Every screen between that moment and the first real interaction is a tax that some users will refuse to pay. AAA apps invert the order: let the user feel the value first, then offer the account/permission/tour as a way to deepen what they're already enjoying. Onboarding becomes a sale, not a tollbooth.

## Exemplars

- **Things 3** — opens to an empty inbox; first task can be created with zero friction
- **Apollo** — Reddit content is browsable before login
- **Halide** — the camera works instantly; settings and account are progressive

## Violators (apps that pay the price)

- **Many fintech onboarding flows** — ten-plus screens before the camera or core surface
- **Hey** — mandatory account-first wall before any product surface

## Why it matters at AAA quality

Pre-action friction is where sixty percent or more of first-launch churn happens. AAA apps treat the first interaction as sacred; the moment the user experiences value is the moment account creation becomes a reasonable ask.
