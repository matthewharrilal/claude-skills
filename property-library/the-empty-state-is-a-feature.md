# The empty state is a feature

Empty states aren't gaps; they're greetings. They orient, teach, and invite the first action.

## What it means

Empty is the most common first impression — every new install opens to empty inboxes, empty libraries, empty feeds. AAA apps treat the empty state as a designed surface with its own purpose: orient the user (where am I?), teach the basics (what does this screen do?), and invite the first action (what should I do next?). A bare "No items" stamp signals that the team thought about the populated state and forgot about everything else.

## Exemplars

- **Things 3** — "Nothing planned for today" framed gently, with the date and a path to add
- **Spotify** — illustrated empty states with browse suggestions baked in
- **Apple Reminders** — smart suggestions appear when the list is empty

## Violators (apps that pay the price)

- **Apps that show literal blank screens** — no orientation, no invitation, no path forward
- **Apps with "No items" stamps and no CTA** — the user is left to figure out what to do

## Why it matters at AAA quality

Empty is the most common first impression. A bare empty state signals an unfinished app — the team designed for the happy path and ignored the entry path.
