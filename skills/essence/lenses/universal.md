# Universal Lenses for Essence Extraction

These five lenses apply to ALL content types. Work through them in sequence.

---

## Lens 1: First Encounter Impressions

### Purpose
Capture raw intuitions BEFORE analytical contamination. First impressions often contain essential truths that expertise obscures. Once you've analyzed deeply, you can't un-know—these intuitions are lost.

### The Critical Rule
This lens MUST be applied BEFORE reading the full content. Skim for 60 seconds maximum, then write.

### Extraction Prompts

Answer these questions immediately, trusting gut reactions:

1. **What is the dominant emotion or energy here?** (one word)
2. **If this were a person, what would their first sentence be?**
3. **What does this remind me of?** (first association, unfiltered)
4. **What surprised me in the first 60 seconds?**
5. **What single word captures my gut reaction?**
6. **If this were a place, what place would it be?**

### Output Format

```
FIRST ENCOUNTER (captured before deep reading):

Dominant energy: [one word]
First association: [what this reminds me of]
Surprise: [what was unexpected]
Gut word: [single word capture]
If it could speak: "[first sentence it would say]"
If it were a place: [what place]
```

### Why This Matters
Analytical work overwrites first impressions. But those impressions often detect things the analytical mind misses—incongruences, vibes, unstated assumptions, the gap between what something says it is and what it actually is. Capture them before they're rationalized away.

## Lens 2: Metaphor Extraction

### Purpose
Identify the root metaphors that structure thought. These aren't decorative—they're the conceptual DNA shaping every decision. Everything important in a domain is understood THROUGH something else.

### Extraction Prompts

#### Find the Central Metaphor
- **What is this thing treating AS something else?**
- Complete the sentence: "Everything here is talked about as if it were a ____"
- Examples of root metaphors:
  - "Code as city" (neighborhoods, infrastructure, zoning)
  - "Data as water" (flow, pipes, dams, flooding)
  - "Users as guests" (hospitality, welcome, accommodation)
  - "Security as warfare" (attacks, defense, territory)
  - "Growth as organism" (health, feeding, evolution)

#### Trace the Entailments
If X is understood as Y, what follows?
- How should things grow or change?
- What does "health" look like?
- What relationships exist between parts?
- What is the "enemy" or "problem"?
- What does success mean?

#### Find the Boundaries
- Where does the metaphor BREAK DOWN?
- What aspects does it illuminate vs. obscure?
- What becomes invisible through this metaphor?

#### Identify Rejected Metaphors
- What metaphor would this thing NEVER use?
- What does that rejection reveal about its identity?

### Output Format

```
ROOT METAPHOR: [the dominant metaphor]

The central frame: [X] is understood as [Y]

What this metaphor REVEALS:
- [thing it makes visible 1]
- [thing it makes visible 2]
- [thing it makes visible 3]

What this metaphor HIDES:
- [thing it obscures 1]
- [thing it obscures 2]

Key entailments (if X is Y, then...):
- [implication 1]
- [implication 2]
- [implication 3]

Rejected metaphors:
- [metaphor this would reject] — because [why]
- [metaphor this would reject] — because [why]
```

### Why This Matters
Metaphors constrain and enable thought. Once you see that a project treats code as a city, you understand why "neighborhoods" feel native and "command chains" feel foreign. The metaphor predicts what will resonate. It's not just descriptive—it's generative.

## Lens 3: Values Excavation

### Purpose
Identify values REVEALED by decisions, not values STATED. Stated values are aspirational—what they want to believe. Revealed values are what their choices prove they actually prioritize.

### The Critical Distinction
- **STATED values**: What they say matters ("We value simplicity")
- **REVEALED values**: What their choices prove matters (but the config has 47 options)

### Extraction Prompts

#### Trace Decisions to Values
For each significant decision you observe, ask:
- What was PRIORITIZED over alternatives?
- What was sacrificed to get this?
- When forced to choose, what won?

#### Look for Absences and Presences
- What is conspicuously ABSENT despite being "standard"?
- What is present despite being "unnecessary"?
- Absences reveal what's not valued; unusual presences reveal what is.

#### Value Detection Signals
Look at these as evidence of underlying values:
- **Time allocation**: Where was time spent? That's what matters.
- **Edge case handling**: What's protected when things go wrong?
- **Error messages**: Who are they written for? That's who's respected.
- **Dependencies chosen**: What's trusted enough to bring in?
- **Documentation depth**: What's explained matters; what's assumed doesn't.

#### Common Value Dimensions
Plot where this lands on these spectrums:
- Simplicity ←→ Power
- Control ←→ Convenience
- Consistency ←→ Flexibility
- Performance ←→ Readability
- Safety ←→ Freedom
- Polish ←→ Speed
- Explicit ←→ Magical
- Individual ←→ Collective
- Opinionated ←→ Agnostic
- Depth ←→ Breadth

### Output Format

```
VALUES HIERARCHY (ranked by evidence weight):

1. [HIGHEST VALUE]
   Evidence: [specific decision or sacrifice that reveals this]

2. [SECOND VALUE]
   Evidence: [specific decision or sacrifice that reveals this]

3. [THIRD VALUE]
   Evidence: [specific decision or sacrifice that reveals this]

4. [FOURTH VALUE]
   Evidence: [specific decision or sacrifice that reveals this]

5. [FIFTH VALUE]
   Evidence: [specific decision or sacrifice that reveals this]

STATED vs REVEALED tensions:
| Stated | Revealed | Evidence |
|--------|----------|----------|
| [claim] | [reality] | [specific example] |

Conspicuous ABSENCES (what's missing that's usually there):
- [absence 1] — reveals [what this says about values]
- [absence 2] — reveals [what this says about values]

Conspicuous PRESENCES (what's there that's usually not):
- [presence 1] — reveals [what this says about values]
- [presence 2] — reveals [what this says about values]
```

### Why This Matters
When you know something consistently chooses simplicity over power, you can predict its response to a complexity-adding proposal. Revealed values are predictive. Stated values are often wrong.

## Lens 4: Worldview Reconstruction

### Purpose
Synthesize findings into a coherent worldview—the complete set of assumptions that must be true for this thing to make sense. This is the deepest layer. When you reconstruct the worldview, you can *think from inside it*.

### The Five Dimensions

#### 1. Ontology — What Exists?
- What are the fundamental entities in this world?
- What categories organize reality here?
- What's considered "real" vs. constructed/arbitrary?
- What has agency? What is passive?

#### 2. Epistemology — How Do We Know?
- What counts as evidence?
- What sources are trusted? Distrusted?
- How is certainty achieved?
- What's explicit vs. tacit knowledge?
- What's considered authoritative?

#### 3. Axiology — What Matters?
- What is the hierarchy of goods?
- What trade-offs are acceptable?
- What is non-negotiable?
- What's the implicit moral framework?
- What would be a violation?

#### 4. Teleology — What Is the Purpose?
- What is this moving toward?
- What does "success" look like?
- What does "failure" look like?
- What's the implied end state?
- What would "winning" mean?

#### 5. Aesthetics — What Is Beautiful?
- What does "elegant" mean here?
- What patterns are considered beautiful?
- What triggers disgust or discomfort?
- What is the style signature?
- What would be considered ugly or inelegant?

### Output Format

```
WORLDVIEW RECONSTRUCTION:

ONTOLOGY (what exists):
[What are the fundamental entities? What's real here?]

EPISTEMOLOGY (how we know):
[What counts as knowledge? What's trusted?]

AXIOLOGY (what matters):
[Value hierarchy, acceptable trade-offs, violations]

TELEOLOGY (the purpose):
[What's this moving toward? What's success/failure?]

AESTHETICS (what's beautiful):
[Elegance, style, taste, disgust triggers]

THE INTEGRATED FRAME:
[2-3 sentences synthesizing how these five dimensions create a coherent way of seeing. What does someone who holds this worldview BELIEVE about reality?]
```

### Why This Matters
Worldview is the deepest layer. When you reconstruct it, you're no longer analyzing from outside—you're inhabiting. You can predict not just what this thing would do, but how it would THINK about new situations it's never encountered.

## Lens 5: Essence Crystallization

### Purpose
Distill everything to the irreducible core. What must remain for this to still be itself? This is compression—taking all the expansion from Lenses 1-4 and finding the kernel.

### Crystallization Process

1. **Re-read outputs from Lenses 1-4**
2. **Ask**: What is the SINGLE insight that, if removed, makes everything else collapse?
3. **Ask**: What is the one sentence the creator would use to explain this to their younger self?
4. **Ask**: What is the ONE THING this is really about?
5. **Write and compress** until no word can be removed without loss.

### Tests for True Crystallization

- **Splitting test**: Can this be split further? If yes, not crystallized.
- **Removal test**: Does removing any word change meaning? If every word is load-bearing, crystallized.
- **Recognition test**: Would the creator say "yes, exactly"? If they would argue, not crystallized.
- **Generative test**: Can new native ideas be derived from this? If it's generative, it's essential.

### Extraction Prompts

1. If you had to explain this thing's soul to someone in 30 seconds, what would you say?
2. What could you REMOVE and it would still be itself?
3. What could you NOT remove without it becoming something else entirely?
4. If this thing could speak one sentence about its own identity, what would it say?
5. What's the kernel—the smallest possible description that contains the whole?

### Output Format

```
ESSENCE STATEMENT:
[2-3 paragraphs of irreducible soul. Not what it does, but what it IS. Dense with meaning. Write as if teaching someone to THINK like this, not ABOUT this.]

THE CRYSTALLINE CORE:
[Single sentence that cannot be compressed further without loss]

NATIVE/FOREIGN TEST:
An idea is NATIVE to this worldview if:
- [criterion 1]
- [criterion 2]
- [criterion 3]

An idea is FOREIGN to this worldview if:
- [criterion 1]
- [criterion 2]
- [criterion 3]

GENERATIVE QUESTIONS:
Questions that emerge naturally from this worldview:
1. [question 1]
2. [question 2]
3. [question 3]
4. [question 4]
5. [question 5]
```

### Why This Matters
Everything before this was expansion—gathering information, tracing implications, reconstructing frames. This is compression. The essence statement should be so dense that unpacking it would regenerate all the analysis. It's the seed that contains the tree.

## Sequence and Integration

### Required Order
1. First Encounter (BEFORE deep reading)
2. Metaphor Extraction
3. Values Excavation
4. Worldview Reconstruction
5. Essence Crystallization

### Integration Points
- First Encounter intuitions should be validated or revised by later analysis
- Root metaphor should explain the values hierarchy
- Values should be derivable from the worldview
- Essence should compress all five dimensions

### Quality Check
After completing all five lenses, verify:
- [ ] First encounter captured BEFORE analysis
- [ ] Root metaphor identified with entailments
- [ ] Values ranked by EVIDENCE, not claims
- [ ] All five worldview dimensions addressed
- [ ] Essence statement is truly irreducible
- [ ] Native/Foreign test is specific enough to use
- [ ] Generative questions are actually generative
