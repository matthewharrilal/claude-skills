# Perceptual Auditing — Skill Definition

---

**If you are consulting this skill BEFORE building:** You are doing it wrong.

**If you are consulting this skill AFTER building:** You are doing it right.

Audit-optimized compositions feel mechanical. Tension-derived compositions feel alive. The guardrails are FLOORS (minimum acceptable quality), not TARGETS (what you aim for). If you are making composition decisions to improve audit scores, you are inverting the process. Build from the content's tension. Then come here to find out whether the result works as a visual experience.

---

## FRESH-EYES PRINCIPLE (NON-NEGOTIABLE)

Perceptual auditors MUST be context-starved. Do NOT provide: mechanism counts, pattern names, build plan details, gate results, prior experiment results, compositional stack theory, or any pipeline vocabulary. If the auditor knows "this should have 12 mechanisms," they will see 12 mechanisms everywhere. Zero context = genuine first impressions.

The auditor receives ONLY: screenshots and the experiential questions below. Nothing else.

---

## The One Rule

> **"React to what you see before you check what you know."**

If an agent's first action after viewing a screenshot is opening a CSS file, the skill has failed.
If an agent's first action is describing what they SEE and FEEL, the skill is working.

## The Three Laws

Every question in this skill passes all three. Every auditor response must honor all three.

1. The answer must require a screenshot (not answerable from source code alone)
2. The answer must be describable in plain language (no CSS vocabulary)
3. A non-designer must be able to validate the answer

## Your Role as Auditor

Your job is to say what you SEE and FEEL. You are not checking rules — you are experiencing a page as its first reader. If something looks wrong, say so. If something looks right, say so. If something almost works, describe what it would take to get there. The builder's creative decisions are protected; your perceptions are sovereign.

---

## SECTION 0: THE EXPERIENTIAL PASS (BEFORE EVERYTHING)

Before you read any question, before you think about what you're evaluating — inhabit the page. This is not a warm-up. This is the audit.

### The Cold Look (5 seconds per viewport)

1. **CLEAR:** You are seeing this page for the first time. You know nothing about it.
2. **LOOK (5 seconds):** Open the screenshot. Do NOT read text. Absorb shape, color, weight.
3. **REACT (immediately):** Write these four responses — they are LOCKED forever:

```
COLD LOOK ({WIDTH}px):
Gut reaction: [one sentence — what did you FEEL?]
Worst thing:  [one element or area — fix this first?]
Best thing:   [one element or area — protect this]
Ship it?:     [one word — YES / REFINE / NO]
```

4. **LOCK:** These responses are FINAL. Nothing you learn later can change them. Your first impression has special status because it cannot be contaminated by analysis.

### The Scroll-Through

After the cold look, scroll through every screenshot in sequence. Do not analyze. Just experience:

- Where did you speed up? (Low-interest zones — you wanted to get past this.)
- Where did you slow down? (High-interest zones — something caught you.)
- Where did you stop? (A designed moment, or a friction point.)

Write a 2-3 sentence account of the scroll experience. This is your experiential anchor. Like the cold look, it has permanent priority — if your anchor found something that no question surfaces later, report it anyway.

### Visual Verification, Not Code Interpretation

You are reading PIXELS, not decoding text from context. The distinction matters:

- **Code interpretation (WRONG):** "I know from the heading structure that this should be Section 3, so I'll evaluate it as a third-level section."
- **Visual verification (RIGHT):** "The text in this area appears small and gray. I cannot read it comfortably at this zoom level."

If you find yourself reasoning about what something SHOULD look like based on semantic context, stop. Describe only what you SEE.

### Priority Override

Comprehension failures ALWAYS outrank aesthetic observations. If text is illegible, if a chart is unreadable, if navigation is invisible — that is your first finding regardless of everything else. A beautiful page you cannot read has failed.

### Contamination Check

If your experiential pass contains pipeline vocabulary — mechanisms, zones, channels, coherence scores, multi-coherence, compositional stack — your pass was contaminated. Strip it and try again using only perceptual language.

## THE 20 EXPERIENTIAL QUESTIONS

These are not a checklist. They are invitations to perceive. Each one asks you to engage with the page at a specific depth and describe what you experience. Answer in prose — what you see, what you feel, what you notice. Not yes/no, not scores, not measurements.

---

### Tier 1: First Encounter

The page is open. You have not scrolled. What is this place?

**E-01: "What do you notice first? Describe it without using any design vocabulary."**

Not "the hero section" or "the typographic hierarchy" — what do you actually see? "A big dark bar at the top." "A lot of warm empty space with small text in the middle." "A single word, very large, surrounded by nothing." Raw descriptions reveal whether the page's intended focal hierarchy actually works.

**E-02: "Scroll through the entire page at reading speed. Where did you speed up? Where did you slow down? Where did you stop?"**

"Speed up" reveals low-interest zones — places the page loses you. "Slow down" reveals high-interest zones — something caught your attention. "Stop" reveals either designed moments or friction points. Describe the scroll as a journey: where did it pull you forward, where did it let you coast, where did it make you pause?

**E-03: "If you had to describe this page's personality to someone who hasn't seen it, what three words would you use?"**

Not what it SHOULD feel like. What it DOES feel like. This is character attribution — you are meeting the page for the first time and forming an impression. The three words are the impression.

---

### Tier 2: Spatial Experience

How does the page use space? Not its measurements — its spatial character. Where it breathes, where it compresses, where it feels generous, where it feels tight.

**E-04: "Find the most generous area of empty space on the page. Does it feel like a pause in a conversation, or like the other person stopped talking?"**

Designed silence and abandoned emptiness look different. A pause holds tension — you expect the next thought. A stopped conversation feels like something went wrong. Which is this?

**E-05: "Find the tightest, densest area. Can you still breathe? Does the density serve the content there, or does it feel like the page ran out of room?"**

Purposeful density serves the content — analytical material SHOULD feel denser. Spatial panic feels like the layout is cramped for the wrong reasons. "Can you still breathe" is literal — notice your physiological response to compression.

**E-06: "At the widest point of the page, does the content feel like it owns the viewport, or like it's been placed in the middle and told to stay there?"**

"Owns the viewport" = the layout uses the available width with authority. "Told to stay" = the content cowers in a narrow strip surrounded by indifferent margins. This is about spatial confidence.

**E-07: "Pick any two adjacent sections. What changes between them? Not what SHOULD change — what DO you actually notice shifting?"**

If you say "nothing changes," that tells us something. If you say "the background gets slightly cooler and the text feels denser," that tells us something else. Report what you perceive, not what you expect.

**E-08: "Divide the page into thirds by scroll depth. Does each third feel like it got the same amount of attention from the designer, or did someone get tired?"**

Visual energy evenly invested = the designer cared about every section. Front-loaded visual interest = the designer invested in the opening and coasted through the ending. Back-loaded = rare but possible. Where does the attention live?

---

### Tier 3: Content-Form Relationship

Does the design SERVE this specific content, or merely CONTAIN it? These questions ask whether the visual treatment and the content are in conversation.

**E-09: "Is there a moment on this page where the visual treatment changes and the content ALSO changes? Does the visual shift match the content shift, or do they feel unrelated?"**

When the content moves from argument to evidence, does the page's visual character shift to match? Or does everything look the same regardless of what the content is doing? Find the coupling — or its absence.

**E-10: "Imagine this content on a plain white page with default styling. What does the current design ADD to your understanding or experience of the content that plain text wouldn't?"**

If you cannot name what the design adds, the composition is cosmetic — it looks professional but does not serve the content. If you can name specific moments where the design illuminates the content, the composition is working.

**E-11: "Is there any section where the design feels like it's FIGHTING the content — where the visual treatment wants to go one direction and the words want to go another?"**

This is tension in the wrong place. When the metaphor's spatial demands conflict with what the content needs — dense visual treatment on light content, airy treatment on urgent content — something is pulling apart. Describe the tug-of-war if you feel it.

**E-12: "If you removed all the text and just looked at shapes, colors, and space — does the page still tell you something about how the content is organized? What does it tell you?"**

Squint until words disappear. What does the structure alone communicate? "There are three distinct zones" or "everything blends into one tone" or "the bottom half feels heavier than the top." The structure's story — told without words.

**E-13: "Find the section where the content is most complex or difficult. Does the visual treatment HELP you through that complexity, or does it add another layer of difficulty?"**

The hardest content is where design earns its keep. If the visual treatment makes dense material navigable, the composition is doing its job. If it adds confusion on top of complexity, it is failing at its primary purpose.

---

### Tier 4: Compositional Coherence

These questions require having experienced the full page. They ask whether the page functions as a unified composition or a collection of individual decisions.

**E-14: "Is there a rhythm to this page — a beat you can feel? Or does it feel more like a series of unrelated events?"**

Scroll through again. Is there a temporal quality — a pulse, a cadence, a musical structure to the sequencing? Or does each section arrive with no relationship to what came before? The rhythm might be regular, syncopated, or building. Or it might be absent.

**E-15: "Does this page have a dramatic peak — a moment where the visual treatment reaches maximum intensity? Where is it? Does it feel earned?"**

A peak that arrives after sufficient build-up feels earned. A peak that appears randomly feels arbitrary. A page with no peak at all feels flat. Where does maximum visual intensity live, and does the journey to it justify its drama?

**E-16: "Pick any design element — a card, a callout, a border treatment. Now find the same type of element in a different section of the page. Does it look like the same element adapted to a new neighborhood, or like the same element copy-pasted?"**

"Adapted to a new neighborhood" = the component responds to its surroundings, getting denser in dense zones, airier in airy zones. "Copy-pasted" = the component is static, identical everywhere regardless of context.

**E-17: "If this page were a piece of music, what would you hear? A single instrument playing one melody? A choir singing the same note? An ensemble playing different parts?"**

Single instrument = one visual channel doing all the work. Choir in unison = multiple channels but all shifting at the same time, saying the same thing. Ensemble = different visual properties with their own independent rhythms contributing to a unified composition. Name the instruments if you hear them.

---

### Tier 5: What's Almost There

These questions look for POTENTIAL — not defects to fix but creative energy that is close to surfacing. This is what makes auditing generative rather than reductive.

**E-18: "What's the single best moment on this page — the one thing you'd point to as evidence of genuine design thinking? Describe what makes it work."**

Find the high-water mark. What the page achieves at its best. This gives the refinement builder a target: "do more of THIS." If you cannot find a single moment, the page has no compositional foothold.

**E-19: "What's the one thing that's ALMOST working — a design decision that has the right idea but doesn't quite land? What would it take to get it there?"**

Near-misses are the highest-value feedback because they represent the shortest distance to improvement. You can sense what the builder was reaching for. Describe the gap between what they achieved and what they almost achieved.

**E-20: "If you could change ONE thing about this page, what would you change? Not the most technically wrong thing — the one change that would make the biggest difference to how the page FEELS."**

By restricting to one change, you must prioritize. By specifying "biggest difference to how it FEELS," you must judge by experiential impact rather than technical severity. This is forward-looking: not "what bothers me" but "what would transform the experience."

---

### Responsive Supplement (for multi-viewport audits)

When screenshots are provided at multiple viewport widths, add these:

**E-R1: "At this narrower width, does the page feel designed for this viewport, or squeezed into it?"**

Designed-for = the layout reimagined itself for a smaller canvas. Squeezed = everything just got smaller or stacked without rethinking.

**E-R2: "Would a user who ONLY ever sees this page at this width feel served or punished?"**

Would they think someone cared about their experience? Or would they feel like an afterthought?

**E-R3: "Does the way elements reorganize at this width make sense for this content? Or did the layout just shrink things to fit without thinking about what the reader needs?"**

Meaningful responsive design responds to content needs at each width. Mechanical responsive design just collapses columns.

## AUDITOR DEPLOYMENT

### 5 Auditors, Each Engaging the Full Experiential Range

Each auditor answers 4 questions, one from each tier (Tier 5 distributes 3 questions across 3 auditors). Every auditor also performs the Section 0 experiential pass (cold look + scroll-through) independently. No auditor sees another's work.

| Auditor | Questions | Engagement Focus |
|---------|-----------|-----------------|
| A | E-01, E-05, E-11, E-17 | First encounter + density + tension + compositional voice |
| B | E-02, E-08, E-14, E-18 | Scroll experience + thirds + rhythm + best moment |
| C | E-03, E-07, E-12, E-19 | Personality + transitions + structure + near-miss |
| D | E-04, E-06, E-13, E-20 | Empty space + spatial confidence + complexity + one change |
| E | E-09, E-10, E-15, E-16 | Content-form + design value + peak + adaptation |

Each auditor's report has two sections:
1. **Section 0 response:** Cold look (locked) + scroll-through narrative (locked) + contamination check
2. **Question responses:** Prose answers to their 4 assigned questions, with screenshot references

### Information Isolation

Each auditor is an independent, context-free encounter with the page. They receive:
- Screenshot file paths (pre-captured at 1440px, 1024px, 768px — cold look + scroll-through at 80% viewport-height steps)
- Their 4 assigned questions
- This skill file's principles (The One Rule, Three Laws, Section 0 protocol, Language Constraint)

They do NOT receive:
- Any other auditor's report
- Build context, gate results, conviction brief, TC brief, or mechanism counts
- Pipeline vocabulary, pattern names, or compositional stack theory
- Knowledge of what the builder intended

### Screenshot-Based Evaluation Protocol

When deployed as part of a pipeline, auditors receive PRE-CAPTURED screenshots. The orchestrator captures all screenshots before spawning auditors, eliminating Playwright contention.

**Auditor workflow:**

1. You receive file paths to saved PNG screenshots
2. Read each screenshot using the Read tool (which renders images visually)
3. Screenshots are captured at 3 viewport widths: 1440px, 1024px, 768px
4. For each viewport: 1 cold-look capture (full page) + sequential scroll-through captures
5. Apply Cold Look Protocol to each cold-look screenshot FIRST — LOCK your reactions
6. Read scroll-through screenshots in sequence (01, 02, 03...) and write your scroll narrative
7. Answer your assigned questions using evidence from screenshots

**You cannot interact with the page.** Your assessment is purely VISUAL — react to what you SEE, describe what you PERCEIVE.

### Screenshot Pre-Capture Protocol (for orchestrator/lead)

Before spawning auditors, the team lead captures ALL screenshots:

1. Serve the HTML file via HTTP (Playwright blocks `file://` protocol)
2. For each viewport width (1440px, 1024px, 768px):
   a. Navigate to the served page
   b. Wait for `document.fonts.ready` (prevents missing-font artifacts)
   c. Disable animations: inject `* { animation: none !important; transition: none !important; opacity: 1 !important; }`
   d. Take cold-look screenshot (full page)
   e. Take scroll-through screenshots at 80% viewport-height steps
3. Use DPR-safe capture settings to prevent black screenshots on Retina displays
4. Validate: check that no screenshot is blank or all-black before proceeding
5. Save screenshots with clear naming: `1440/cold-look.png`, `1440/scroll-01.png`, etc.

## LANGUAGE CONSTRAINT (NON-NEGOTIABLE)

### What Auditors Cannot Say

**Language HARD BLOCK:** Answers may NOT contain: px, rem, em, %, hex, rgb, rgba, border-radius, box-shadow, padding, margin, font-size, font-family, line-height, max-width, min-width, flex, grid, gap, opacity, z-index, overflow, display, position, or ANY CSS property name.

### What Auditors Say Instead

heavy, light, cramped, spacious, jarring, smooth, floating, grounded, anxious, confident, broken, polished, warm, cold, sharp, soft, cluttered, breathing, stacking, flowing, stuck, drifting, generous, tight, airy, dense, deliberate, abandoned, earned, forced, musical, monotone, alive, flat

The language constraint is the most concrete enforcement of the experiential frame. It forces perceptual language by prohibiting measurement language. Describe what you EXPERIENCE, not what you could measure.

### Severity Language

When describing how serious something is, use the perception track:

- **WOULD-NOT-SHIP:** A designer would refuse to release this. Something is genuinely broken or wrong.
- **LOOKS-WRONG:** Something is visually off. It catches your eye for the wrong reasons.
- **COULD-BE-BETTER:** A polish opportunity. The page would benefit but functions without the change.

## THE WEAVER: CREATIVE SYNTHESIS

The Weaver reads all 5 auditor reports and the scroll-through screenshots, and produces creative direction for the refinement builder. Not a fix list. Not scores. Artistic prose that captures what is working, what is almost there, and what direction to take.

### The Weaver's Process

1. **View the screenshots yourself.** Before reading any auditor report, scroll through every screenshot as a reader. Write a 3-sentence first impression. This is your EXPERIENTIAL ANCHOR. It has permanent priority — if your anchor found something that no auditor caught, your anchor takes precedence.

2. **Read all 5 auditor reports.** Notice convergence (3+ auditors describe the same experience) and divergence (one auditor perceives something the others missed). Both are valuable — convergence confirms what is real; divergence surfaces what is subtle.

3. **Produce your three outputs.**

### Output 1: The Experience Portrait (~15 lines)

A single, coherent description of what it feels like to experience this page. Not an average of opinions — a PORTRAIT that captures what the auditors collectively perceived.

Content:
- What the page FEELS like as a scroll experience (tempo, rhythm, emotional arc)
- Where the page SUCCEEDS (strongest moments across auditor reports)
- Where the page STRUGGLES (consistent pain points across auditor reports)
- What PERSONALITY the page has (from E-03 responses)
- One-sentence experiential summary: "This page feels like ___"

Write the portrait AS IF describing a piece of music or a room you have walked through. Capture gestalt, not components.

**Example:**

```
This page opens with warmth and confidence — the header feels decisive, the
first section invites you in. The descent through the middle sections has
genuine momentum: you feel the content compressing, the visual weight
increasing. The grid zone in section 3 works structurally but breaks the
vertical flow — you shift from diving to browsing and back, and the
return to diving feels slightly forced.

The dramatic peak at section 4 lands hard — three auditors independently
called it the best moment on the page. But the recovery is too fast:
section 5 arrives before the disruption settles, and the emotional impact
dissipates.

The closing section needs more room to release — the page ends abruptly
instead of surfacing gradually.

This page feels like a confident lecture that rushes its conclusion.
```

### Output 2: The Creative Direction (~10 lines)

What the refinement builder should FOCUS ON. Not a fix list — a creative brief for the next compositional pass. Written as direction, not correction.

Use the AMPLIFY / RELEASE / DEEPEN structure:

- **AMPLIFY:** The composition's best moment. Extend it, echo it elsewhere, let its energy shape more of the page. (Drawn from E-18 responses.)
- **RELEASE:** Where the page is holding tension that should resolve. Give the reader room where the page is currently tight, or let the energy settle where it is currently abrupt. (Drawn from convergent pain points.)
- **DEEPEN:** What is almost working — the near-miss that represents the shortest distance to significant improvement. (Drawn from E-19 responses.)
- **THE GAP:** The distance between the page's personality (from E-03) and its best self. What would close that gap?

For each specific issue identified, classify its fix type:
- **MECHANICAL:** CSS value change, straightforward property adjustment
- **STRUCTURAL:** HTML restructuring needed, element reordering or wrapper changes
- **COMPOSITIONAL:** Design rethinking needed, metaphor or spatial model revision

This classification helps the REFINE builder prioritize: MECHANICAL fixes are quick wins, STRUCTURAL fixes require careful surgery, COMPOSITIONAL issues may need a fresh creative pass.

Write this FOR a creator, not for a manager. It should make the refinement builder excited to create, not anxious about compliance.

**Example:**

```
AMPLIFY: The dark inversion at section 4 is the page's strongest moment.
The three sections preceding it build toward it effectively. Can the grid
zone (section 3) participate in this build-up rather than interrupting it?

RELEASE: The recovery from section 4 to section 5 needs TIME. The content
shifts from provocation to evidence. Give the reader a decompression moment
between them — not empty space, but a deliberate change of state.

DEEPEN: The closing section wants to feel like surfacing after a dive. Right
now the dive ends and you're back on land. The transition from bedrock to
resolution needs more gradient — let the reader feel themselves ascending.

THE GAP: Three auditors used the word "formal" where the brief says "warm."
The opening is confident but not warm. Can the conversational voice show up
earlier in the spatial rhythm?
```

### Output 3: The Verdict (3 lines)

Three verdicts only:

| Verdict | Meaning | What Happens |
|---------|---------|-------------|
| **SHIP** | The page achieves its creative intent. Minor opportunities remain but the composition is complete. | Pipeline ends. |
| **REFINE** | The page has a compositional foundation but needs another creative pass. The direction is clear. | Refinement builder receives artifact + reflection + creative direction. |
| **RETHINK** | The page's compositional foundation is not working. A different approach is needed. | TC re-invocation with different metaphor or significantly revised brief. |

No numerical scores. The verdict is a creative judgment, not a calculation. The Weaver reads the experience portrait and the auditor responses and makes a call. The gate runner handles numerical compliance separately.

For REFINE and RETHINK, state the reason in one sentence:
- REFINE: "The descent works but the transitions need graduation."
- RETHINK: "The organizing metaphor is fighting the content's natural structure."

### Weaver and Gate Runner: Different Jobs

| | Gate Runner | Weaver |
|---|-----------|--------|
| **Input** | HTML/CSS artifact | 5 auditor experiential reports |
| **Output** | Binary pass/fail on programmatic gates | Experience portrait + creative direction + verdict |
| **Language** | "GR-18 FAIL: background delta 8 RGB < 15 threshold" | "The zone transitions are invisible — the page feels like one undifferentiated space" |
| **Audience** | Orchestrator (for routing decisions) | Refinement builder (for creative direction) |

Both are needed. The gate runner catches mechanical failures (wrong values, insufficient spacing, missing landmarks). The Weaver catches experiential failures (page feels flat, rhythm is monotonous, peak does not land). A page can pass all gates and still feel lifeless. A page can fail several gates and still feel alive.

## BRIDGING QUESTIONS: WRITING PROMPTS

After creating an artifact, the builder answers these prompts to produce a reflection. This reflection becomes tissue for the next context window — not compliance data, but creative state. Dimensions (a), (b), and (f) are REQUIRED. Dimensions (c), (d), and (e) are OPTIONAL — answer them when they produce genuine insight, skip when they would be forced.

### (a) Conviction [REQUIRED]

"Close your eyes and picture the page you were trying to make — not the one you made, but the one in your head before you started writing CSS. What does it look like? Where does the finished artifact match that picture? Where does it diverge?"

Follow-up: "What's the FEELING you wanted the reader to have at the end of scrolling? Not 'informed' or 'impressed' — the specific emotional register. And does the page achieve it?"

### (b) Alternatives [REQUIRED]

"Name two roads you didn't take. For each one: was it the constraints that stopped you, your own judgment, or running out of context? If the constraints stopped you, do you think they were right to?"

Follow-up: "If you could break ONE rule of the design system for this page, which rule would you break and what would you do?"

### (c) Surprises [OPTIONAL]

"Was there a moment where you wrote CSS and the result was better than what you planned? What happened? Was there a relationship between elements that you didn't design but that emerged from the content's structure or the metaphor's logic?"

Follow-up: "Did the content's own shape suggest something the brief didn't predict? A rhythm, a visual relationship, a natural grouping?"

### (d) Impulses [OPTIONAL]

"What did you WANT to do that the vocabulary wouldn't let you? Not 'I wish I could use gradients' — that's wishing for a different system. Something like 'I wanted THIS specific visual effect for THIS specific moment and couldn't find a way to express it within these tools.'"

Follow-up: "Is there a component that doesn't exist yet but should? What would it do?"

### (e) Experience [OPTIONAL]

"Scroll through your page slowly, as if you're seeing it for the first time. Don't think about whether it's correct — just notice what you experience. Where do you feel pulled forward? Where do you feel friction? Where do you feel satisfaction? Where do you feel doubt?"

Follow-up: "If someone asked 'how does this page make you feel?', what would you say? Not what SHOULD it make someone feel — what does it actually make YOU feel, having just built it?"

### (f) Unresolved [REQUIRED]

"Name a tension in this page that you couldn't fully resolve — not a bug or a mistake, but a genuine aesthetic question where two good options competed and neither won clearly. What were the two options? Why couldn't you choose?"

Follow-up: "If a different builder inherited this page and asked 'what's the most interesting unsolved problem here?', what would you tell them?"

---

## BRIDGING QUESTIONS: RECEIVING PROMPTS

When a new builder receives an artifact, its conviction brief, and the previous builder's 6-dimension reflection, these prompts orient them toward creative continuation rather than critical correction.

**R-01:** "Read the conviction dimension first. Before looking at the artifact, picture the page the previous builder was trying to make. What do you see?"

**R-02:** "Now look at the artifact. Where does the previous builder's vision show through clearly? Start there — those are the composition's strengths. Build FROM them, not AWAY from them."

**R-03:** "Read the alternatives and impulses dimensions. Which of the previous builder's rejected paths or suppressed creative energy resonates with you? Is there one you want to explore?"

**R-04:** "Read the surprises dimension. The previous builder discovered something the brief didn't predict. Does that discovery suggest a direction you want to push further?"

**R-05:** "Read the experience dimension. Now scroll through the artifact yourself. Where does your experience match the previous builder's? Where does it diverge? The divergence points are where your fresh perspective adds the most value."

**R-06:** "Read the unresolved dimension. The previous builder left you a gift — an aesthetic tension they couldn't resolve. You don't have to resolve it either. But if you see a way through that they didn't, take it."

**R-07:** "Having read all six dimensions: what's the ONE thing you want to do with this page? Not the longest list of fixes — the single creative act that would make the biggest difference. Start there."

## METAPHOR AWARENESS (FOR AUDITORS)

When auditing a page that has an organizing metaphor — and you will not be told what it is — you do not need to know what the designer intended. Apply this test:

1. Mentally REMOVE all text, headings, and labels from the page
2. Look at ONLY the visual structure: backgrounds, spacing, borders, layout shifts
3. Ask: "Does this visual structure suggest a spatial model?"

- **YES, clearly:** The visual structure alone communicates organization. The metaphor is structural.
- **YES, vaguely:** There is a feel but no clear spatial logic. The metaphor is atmospheric.
- **NO, but labels explain it:** Remove labels and the metaphor vanishes. The metaphor is announced.
- **NO, nothing:** No detectable metaphor in visual structure.

This is not a pass/fail. It is a perception. Report what you see. Questions E-12 (shapes without text) and E-11 (design fighting content) naturally engage with metaphor quality without requiring you to name or judge the metaphor itself.

**The principle:** The metaphor shapes experience; the guardrails prevent it from breaking experience. When a page looks unusual because its spatial decisions serve a concept, the question is not "does this follow convention?" but "does this work as a visual experience despite — or because of — the unusual choices?"

## HOW THE WHOLE SYSTEM CONNECTS

```
TC Pipeline  -->  CONVICTION BRIEF
  --> Builder creates artifact
    --> Builder answers WRITING PROMPTS --> 6-dimension REFLECTION
      --> Auditors answer EXPERIENTIAL QUESTIONS --> descriptive prose
        --> Weaver produces EXPERIENCE PORTRAIT + CREATIVE DIRECTION + VERDICT
          --> If REFINE: next builder receives artifact + reflection + creative direction
            --> Next builder answers RECEIVING PROMPTS --> enters creative state
              --> Next builder creates refined artifact
                --> Next builder answers WRITING PROMPTS --> new reflection
                  --> [cycle continues until SHIP]
```

Every node in this flow produces CREATIVE TISSUE, not compliance data. The gate runner handles compliance separately, in parallel, with binary precision. The human-facing pipeline is entirely about creative experience, creative direction, and creative continuation.
